# AI Sana — MVP каталога задач

Демо для кейса HackAlem AI: сервис превращает короткое описание бизнес-задачи в понятный бриф, показывает рейтинг готовности и публикует задачу в каталоге команд.

## Как запустить

Откройте `index.html` в браузере. Сборка и зависимости не нужны.

## Что реализовано

- ввод черновика бизнес-задачи;
- AI-уточняющие вопросы и выбор ответов;
- рейтинг готовности и рекомендации;
- каталог задач;
- имитация публикации задачи и отклика команды.
- кабинет бизнеса с выбором команды-исполнителя.
- рабочая навигация между экранами;
- понятная форма с живым рейтингом готовности;
- встроенный AI-помощник с подсказками;
- поиск и фильтры по каталогу;
- интерактивные отклики и выбор команды.

## Демонстрационный сценарий

1. Введите черновик задачи.
2. Нажмите «Продолжить с AI».
3. Выберите ответы на вопросы AI Sana.
4. Нажмите «Собрать бриф», затем «Опубликовать задачу».
5. В каталоге нажмите «Откликнуться».
